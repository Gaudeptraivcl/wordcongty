# Skills

## gia-vlxd-thanh-hoa — Giá VLXD Thanh Hóa Quý 3 & Quý 4/2023

Skill cho Claude tra cứu giá vật liệu xây dựng công bố của tỉnh Thanh Hóa:
- Quý 3/2023 — Công bố 7380/LSXD-TC ngày 25/10/2023 (Liên Sở XD – TC)
- Quý 4/2023 — CV 529/SXD-KTXD ngày 19/01/2024 (Sở Xây dựng)

### Cài đặt

**Claude.ai / Claude Desktop (cá nhân hoặc cả tổ chức):**
1. Tải file `gia-vlxd-thanh-hoa.zip` trong thư mục này.
2. Vào **Settings → Capabilities → Skills → Upload skill**, chọn file zip.
3. Với gói Team/Enterprise, quản trị viên có thể chia sẻ skill cho cả tổ chức.

**Claude Code:** chép thư mục `gia-vlxd-thanh-hoa/` vào `~/.claude/skills/` (dùng cho mọi dự án) hoặc `.claude/skills/` trong repo (dùng chung cho nhóm qua git).

### Cách dùng
Hỏi tự nhiên, ví dụ:
- "Giá xi măng PCB40 ở huyện Nga Sơn quý 4/2023?"
- "So sánh giá thép Thái Nguyên quý 3 và quý 4 năm 2023"
- "Các mỏ đá 1x2 ở Vĩnh Lộc giá bao nhiêu?"

Lưu ý: dữ liệu số hóa từ bản scan; khi dùng cho hồ sơ chính thức nên đối chiếu văn bản gốc (số trang gốc ghi trong từng mục).
